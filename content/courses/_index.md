**Purpose.** The catalogue. A learner or a manager lands here to find the one course that closes a real skills gap, and to see immediately what it costs and when it next runs.

**Contains.**
- Filter row: track, level (foundation, intermediate, advanced), format, delivery mode, language
- Course cards generated from `data/courses.yaml`: code, level, duration, price from, next date, seats left
- Grouping by track: AI and agents, cloud and platform, governance and leadership
- A "not sure where to start" router into /learning-paths/
- In-house note: every catalogue course can be run privately for one team, unchanged or tailored
- Sample lab callout so a buyer can see the hands-on ratio before paying
- Version and last-reviewed stamp per course, because curriculum drift is the failure mode here

**Primary CTA.** Open a course page, or request the same course in-house.
**Links to.** /learning-paths/, /formats/, /schedule/, /pricing/, /for-teams/in-house-training/.
